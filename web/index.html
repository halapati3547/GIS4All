How it works

Three steps. Nothing is sent or filed; the tool drafts and a person decides.

1
Screen

Join zoning, land use, flood, fire, earthquake and transit layers for every parcel.

2
Test

Run each law's written tests. Each answer is pass, fail or "can't check yet", with its source.

3
Call

Rank the sites, list what to confirm, and draft the first call with Claude.

Before, for Habitat's acquisitions lead

  • Waits for someone to offer a site.
  • Checks one parcel at a time by hand.
  • No list to compare against.

After

  • Opens a ranked list of sites to call this month.
  • Sees why each fits and what to confirm first.
  • Checks any Santa Ana address in seconds.

Against the judging criteria

What we can show for each of the four areas.

Impact
Targets land, the biggest cost.

Built for one real role at Habitat OC, with a call list it could use next month.

Works
Live on real public data.

42,684 real parcels, 9 public layers, a source and date on every test, unknowns shown as unknown.

Scale
One command per city.

The regional data already covers all 34 OC cities. Each site exports as data for other tools.

Innovation
Joins law to land.

Matches the IRS nonprofit list to parcels to find church-owned land for SB 4, which no free map shows.

What it does not know

A screen, not an approval. Missing data is shown as "unknown", never guessed.

Checked by a person

Historic districts, recent tenants, and true ownership. Church ownership is a lead from a public registry.

Labelled assumptions

How Santa Ana's zoning codes map to each law, and the score weights. Both are shown in the tool.

Known gap

The regional housing-plan layer has no Santa Ana sites yet, so city-picked sites get no extra credit.
