
## API and UI

- **Data loading.** `api/main.py` loads `data/candidates.json` + `data/meta.json` at startup. If `candidates.json` is missing it falls back to `data/sample/*.sample.json` (made-up sites, top-level `"SAMPLE"` key) and sets `meta.using_sample=true`; the UI then shows a yellow "Showing SAMPLE data" banner. Restart the server after the pipeline writes new data.
- **meta.json shape (assumed).** `{city, built_at, sources:[{id,name,url,checked,status:"ok"|"failed",rows,affects:[test ids]}], weights:{...,label:"ASSUMPTION"}, counts:{...}}`. Any missing key is filled from `candidates.json`. `affects` drives the "goes UNKNOWN if failed" column.
- **Hazard exclusion.** A site counts as excluded if `excluded_by_hazard` is true or `hazards.flood/fire.result == "FAIL"`. `excludeHazardUnknown` drops sites whose flood or fire result is UNKNOWN.
- **Pathway filter.** `pathway=X` keeps sites with a pathway of that id whose status is not FAIL. `pathway=HE` also matches `housing_element.listed`.
- **Pathway ids** expected: `SB9, SB684, AB2011, SB4, SB79, HE`. Statuses: `PASS, FAIL, UNKNOWN, FLAG` (INFO renders grey).
- **Export.** `for_lane_2.pathway_is_ministerial` is true when SB9/SB684/AB2011/SB4 is PASS; `clock_days: 60` is labelled ASSUMPTION.
- **Claude.** Placeholder by default: with `MOCK_CLAUDE` set or no `APP_ANTHROPIC_API_KEY`, `/api/explain` returns a template built from pathway statuses and unknowns, tagged `source:"offline template"`. Templates are not cached so a later real call can replace them; real responses are cached to `data/explanations/{apn}.json`. Real path: `claude-sonnet-5-5`, max_tokens 700, 20 s timeout, 1 retry, numbers not in the input replaced with "[see card]".
- **Address lookup** returns 501 `{"detail":"address lookup lands in M6"}`; the UI shows it inline.
- **Front end.** Vanilla JS, Leaflet 1.9.4 from cdnjs, OSM tiles; no build step. Stacks below 1000 px.

## Pipeline

Built 2026-11-07 by the pipeline agent. Re-run: `. .venv/bin/activate && python -m pipeline.build --city "Santa Ana"` (offline from `data/raw/` once cached; ~80 s).

- **Centroids (D1).** The SCAG MapServer ignores `returnCentroid=true` (no centroid in the response), so we fetch `returnGeometry=true&geometryPrecision=5&outSR=4326` and use the mean of the outer-ring vertices. 42,896 rows -> 42,684 unique APNs (stacked/duplicate APNs: keep the largest polygon).
- **LU24 codes (D2).** No coded-value domain and no renderer labels on the layer, but the layer metadata `description` contains the full "2024 SCAG Land Use Codes" legend. We copied it into `pipeline/codes.py` (source: `https://maps.scag.ca.gov/scaggis/rest/services/LDX/Existinglanduse_poly_OR/MapServer/0?f=json`). This **contradicts the spec's assumed families** (6xxx vacant, 8xxx open space, 3xxx industrial): in SCAG's legend 13xx is industrial, 18xx open space, 1900/3000/3100/3200/3300 vacant, 2xxx agriculture. We used the published legend, not the assumption. Vacant = 1900, 3000, 3100, 3200, 3300; surface parking = 1247 (Public Parking Facilities), 1414 (Park-and-Ride Lots); religious facilities = 1245.
- Santa Ana LU24 distinct values (count): blank 80, 1110 33398, 1111 286, 1112 15, 1120 775, 1122 1448, 1123 756, 1124 30, 1125 1, 1130 93, 1140 206, 1200 481, 1210 600, 1211 20, 1212 1, 1220 1134, 1221 2, 1222 299, 1223 61, 1230 21, 1231 1, 1233 34, 1240 67, 1241 71, 1242 11, 1243 10, 1244 5, 1245 172, 1246 16, 1247 31, 1252 2, 1260 139, 1261 2, 1262 11, 1263 3, 1264 14, 1265 6, 1266 1, 1270 3, 1300 71, 1310 33, 1311 968, 1313 3, 1320 53, 1323 7, 1340 416, 1400 15, 1413 16, 1415 4, 1416 1, 1430 1, 1431 8, 1434 3, 1435 1, 1436 1, 1437 4, 1440 4, 1500 11, 1600 85, 1700 2, 1800 27, 1810 27, 1820 12, 1880 140, 1900 312, 2600 1, 3000 36, 3100 326, 9999 2.
- **Zoning (ASSUMPTION).** Base code (text before `-`) exact match: R1 single-family; R2/R3/R4 multifamily; C1/C2/C5/P commercial/office; M1/M2 industrial; O/A1 open space/public. Everything else (SD-xx, SP-x, C4, CSM, GC, CR, OZ1 ...) is unmapped -> zone tests UNKNOWN. To confirm against the Santa Ana municipal code.
- **Housing element (D3).** Fields: `Assessor_Parcel_Number`, `Jurisdiction`, `Low_Income_HE_Capacity`, `Moderate_Income_HE_Capacity`, `Above_Moderate_Income_HE_Capacity`, `Total_HE_Capacity`. The layer has 2,126 Orange County rows but **zero Santa Ana rows** (by Jurisdiction and by APN digits). So `he.listed` is UNKNOWN for every parcel ("check the city's adopted inventory"), not FAIL, and the 15 he_listed points are never awarded.
- **Hazards.** D4 71 polygons in bbox (FAIL if FLD_ZONE starts A or V); D5 0 polygons in bbox -> fire PASS "no LRA zone intersects parcel"; D6 5 polygons -> FLAG only. No ranked parcel in the top 1,000 is hazard-gated.
- **Transit.** D7 243 HQTA polygons, D8 19 stops (805 m haversine).
- **Approximations.** AB 2011 adjacency = industrial-use (LU 13xx) centroid within 60 m; SB 4 buffer = within 366 m; SB 4 perimeter = >=75% of neighbouring centroids within 100 m have urban use (not vacant/open space/agriculture; blank/unknown codes ignored).
- **Result values.** Besides PASS/FAIL/UNKNOWN, tests may be `FLAG` (liquefaction, SB 79) or `N/A` (ab2011.corridor); a pathway with only PASS/FLAG/N/A is PASS. SB 79 pathway status is FLAG or FAIL, never PASS. Because `haz.historic`, `sb9.tenancy`, `sb4.owner_proxy` and `haz.wetland_farmland` are always UNKNOWN, **no statutory pathway can reach PASS today**; best_pathway is therefore at most 12, and the max score this run is 52. best_pathway considers SB9/SB684/AB2011/SB4 only (not SB79/HE).
- **Not run.** D10/D12 owner proxy (owner_lead null, sb4.owner_proxy UNKNOWN), D13 surplus history (null). HCD fact-sheet thresholds taken from the spec; PDFs not re-opened in this run.
- **Output size.** candidates.json holds the top 1,000 of 39,484 ranked sites (~11 MB; `--top N` to change). Ties broken by size_fit then APN. Addresses (D9, `ASSESSMENT_NO IN ('001-011-05',...)`, digits-normalised join) fetched for the top 300: 282 matched, 170 of the top 1,000 have a real address (many vacant lots return "ADDRESS NOT AVAILABLE", stored as null).
